# מכלול מידע לציבור – אתר הדרכה

אתר הדרכה סטטי (HTML/CSS/JS, ללא תלות בבנייה) לבעלי תפקידים ברשויות המקומיות בישראל, המרכז בצורה נגישה
את עקרונות ההסברה, מבנה הרשות המקומית בחירום, תפקידי "מכלול מידע לציבור", סדר הפעולות הנדרש וכלי ההפצה
העומדים לרשות הרשות המקומית.

## מבנה האתר

| עמוד | תיאור |
|---|---|
| `index.html` | עמוד בית וניווט מהיר לכל הפרקים |
| `principles.html` | עקרונות ההסברה, מעגל הזהב, רלוונטיות ואמינות |
| `structure.html` | הבסיס החוקי ומבנה הרשות המקומית בחירום |
| `info-unit.html` | מכלול מידע לציבור – ייעוד, תפקידים ומבנה פנימי |
| `procedures.html` | סדר פעולות לפני/בכניסה/בשגרת/בעת אירוע חירום |
| `strategy.html` | בניית אסטרטגיית הסברה ומודל המסרים |
| `stakeholders.html` | גורמי ממשק וסמכויות (פיקוד העורף, משרדי ממשלה ועוד) |
| `tools.html` | כלים וערוצי הפצה (חפ"ק, אתר, אפליקציה, מוקדים טלפוניים) |
| `glossary.html` | מילון מונחים |
| `about.html` | אודות ומקורות |

## הרצה מקומית

פתיחת `index.html` בדפדפן מספיקה – אין תלות בשרת או בכלי בנייה.

## פרסום ב-GitHub Pages

1. היכנסו ל-**Settings → Pages** בריפו.
2. בחרו Source: `Deploy from a branch`, Branch: `main`, תיקייה: `/ (root)`.
3. האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.

## הבהרה

האתר מיועד למידע כללי ולצורכי הדרכה בלבד, ואינו מהווה תחליף לנהלים הרשמיים ולהנחיות המחייבות של
פיקוד העורף, משרד הפנים והגורמים המוסמכים. בשעת חירום יש לפעול אך ורק לפי ההנחיות הרשמיות המעודכנות.
